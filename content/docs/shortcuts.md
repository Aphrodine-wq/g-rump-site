Complete shortcut reference for G-Rump.

## Global Shortcuts

| Shortcut | Action |
|---|---|
| `⌘N` | New Chat |
| `⌘,` | Open Settings |
| `⌘.` | Stop generation |
| `⌘L` | Focus message input |
| `⌘\` | Toggle sidebar |
| `⌘E` | Export current conversation as Markdown |
| `⌘⇧L` | Layout Customizer |
| `⌘⇧K` | Keyboard Shortcuts overlay |

## Chat Input

| Shortcut | Action (Return-to-Send ON) | Action (Return-to-Send OFF) |
|---|---|---|
| `Return` | Send message | New line |
| `⇧Return` | New line | New line |
| `⌘Return` | — | Send message |

Configure Return-to-Send in **Settings → Behavior**.

## Navigation

| Shortcut | Action |
|---|---|
| `⌘1`–`⌘9` | Switch to panel 1–9 |
| `⌘0` | Toggle right panel |

## Viewing

| Shortcut | Action |
|---|---|
| `⌘+` | Increase content size |
| `⌘-` | Decrease content size |
| `⌘0` | Reset content size |
